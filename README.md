# no-memory
脳のメモリ解放 (Brain Memory Release)概要「脳のメモリ解放」は、学習過程で遭遇する技術用語や複雑な概念を、Google Gemini APIを活用して簡潔な解説として蓄積するパーソナルナレッジベースです。本システムは、ブラウザベースのフロントエンド、Google Apps Scriptによるバックエンド、およびGoogleスプレッドシートをデータベースとして統合したサーバーレスアーキテクチャを採用しています。システムアーキテクチャ本システムは、以下のコンポーネントで構成されています。フロントエンド: GitHub PagesにてホストされるWebアプリケーション。localStorageを用いたユーザー識別機能および非同期通信（Fetch API）による動的なUI更新を行います。バックエンド: Google Apps Script (GAS) がAPIエンドポイントとして機能し、ユーザーからのリクエストに応じたデータのCRUD処理およびGemini APIへのプロンプト送信を仲介します。データストレージ: Googleスプレッドシートを構造化データベースとして使用。UserIDをキーとしたマルチテナント型のデータ管理を行い、情報の整合性を維持します。主な機能IDベースのマルチユーザー管理: UserIDを用いたデータのフィルタリングにより、単一のGASプロジェクト内で複数ユーザーのデータを独立して管理可能です。自動的な知識抽出: 自然言語処理モデルによる解析。入力された単語から「解説」「関連用語」「参考URL」を自動抽出し、構造化されたJSONとして記録します。ライフサイクル管理: アーカイブ処理スクリプトにより、一定期間（3日間）経過したデータを自動的に別シートへ転送し、メインデータベースの検索効率を維持します。復習通知機能: 蓄積されたデータの中で、特定の期間内に生成された項目を抽出し、ダッシュボード上で未読として可視化します。技術スタックFrontend: HTML5, CSS3, ES6+ JavaScriptBackend: Google Apps Script (V8 Runtime)API: Google Generative AI (Gemini 2.5 Flash)Infrastructure: GitHub Pages, Google Cloud Platform (Apps Script)データ構造（Googleスプレッドシート）データベースとなるスプレッドシートは、以下のカラム構成で定義されます。カラム名データ型説明UserIDStringユーザー識別用の一意なキーTimestampDateTimeデータ生成日時WordString入力単語ExplanationTextAIによる解説文URLString関連参考資料のURLRelatedArray/Stringカンマ区切りの関連単語リストセットアップ手順Googleスプレッドシートを作成し、上記スキーマに従って列を設定してください。Apps Scriptエディタにソースコードを配置し、ウェブアプリとしてデプロイしてください。デプロイ時に生成されるURLをフロントエンドの定数 GAS_URL に設定してください。公開されたHTMLファイルをGitHubリポジトリに配置し、GitHub Pages機能を有効化してください。
